# NumPy Practice

This is my Python practice project on **NumPy for numerical computation and data analysis**.

## What I Practiced

- Creating 1D, 2D, and 3D NumPy arrays
- Reshaping arrays
- Vectorised operations
- Addition and multiplication
- Aggregation across axes
- Boolean masking
- Fancy indexing
- Mean and standard deviation
- Percentiles
- Correlation
- Comparing NumPy performance with Python loops
- Working with 1 million rows

## Tools Used

- Python
- NumPy
- VS Code
- Git
- GitHub

## About

I created this project to practice NumPy and understand how arrays and vectorised operations can be used for efficient numerical computation and data analysis.

I also compared NumPy operations with Python loops using a 1 million-row dataset to understand the performance benefits of vectorisation.
