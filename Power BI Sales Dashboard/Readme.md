# Power BI Sales Analytics Dashboard

This project is a Power BI sales analytics dashboard created using a CSV sales dataset.

## Report Pages

### 1. Sales Overview
- Total Sales
- Total Orders
- Total Quantity
- Average Order Value
- Sales by Category
- Sales by Region
- Date slicer
- Region slicer
- Category slicer

### 2. Drill-Down
- Region
- Category
- Customer
- Sales drill-down analysis

### 3. KPI Summary
- Total Sales
- Total Orders
- Total Quantity
- Average Order Value
- Monthly Sales Trend

## Tools Used

- Power BI Desktop
- Power BI Service
- CSV
- DAX

## Key Features

- Interactive slicers
- KPI cards
- Sales analysis by region and category
- Drill-down functionality
- Monthly sales trend
- Published to Power BI Service
