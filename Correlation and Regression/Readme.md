# Correlation and Linear Regression

This project covers correlation analysis and simple linear regression using Python.

## Practical Tasks

- Calculate Pearson correlation coefficient
- Calculate Spearman correlation coefficient
- Visualise correlations using a heatmap
- Create a scatter matrix
- Build a simple linear regression model using Scikit-learn
- Calculate R²
- Calculate MAE
- Calculate RMSE
- Plot residuals
- Check regression model assumptions

## Dataset

The project uses the `Cynaris_Sales_Dashboard.csv` retail sales dataset.

The main variables used are:

- Quantity
- Cost
- Revenue

## Correlation Analysis

Pearson and Spearman correlation coefficients were calculated to understand the relationship between cost and revenue.

## Visualisations

The following charts were created:

- Correlation Heatmap
- Scatter Matrix
- Linear Regression Plot
- Residual Plot
- Residual Distribution
- Q-Q Plot

## Linear Regression

A simple linear regression model was created using:

- Independent variable: Cost
- Dependent variable: Revenue

The model was built using Scikit-learn's `LinearRegression`.

## Model Evaluation

The model was evaluated using:

### R²

Measures how much variation in the dependent variable is explained by the model.

### MAE

Measures the average absolute prediction error.

### RMSE

Measures prediction error while giving larger errors more weight.

## Model Assumptions

The following assumptions were checked:

- Linearity
- Constant variance
- Normality of residuals
- Independence of observations

Residual plots, residual distribution, and Q-Q plots were used for the analysis.
