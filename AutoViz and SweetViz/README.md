# AutoViz and SweetViz EDA

This project explores automated exploratory data analysis using AutoViz and SweetViz.

## Dataset

The project uses an Indian retail sales dataset containing 1,500 records.

## AutoViz

AutoViz was used to automatically generate visualisations and explore relationships between variables.

## SweetViz

SweetViz was used to create an interactive HTML EDA report.

## Tasks Completed

- Loaded the Indian retail dataset
- Ran AutoViz
- Generated automated visualisations
- Exported analysis output
- Identified three business insights
- Ran SweetViz
- Generated an HTML report
- Compared AutoViz and SweetViz
- Documented a recommendation for business stakeholders

- SweetViz
