# Looker Studio Sales Dashboard

This project is an interactive sales analytics dashboard created using **Looker Studio** and **Google Sheets**.

## Dashboard

[View the Live Looker Studio Dashboard](https://datastudio.google.com/reporting/e5cddab5-82a0-4959-a80b-0e48b3791a3b)

## Dashboard Features

The dashboard includes the following visualizations and interactive controls:

- Total Revenue Scorecard
- Revenue by Region Bar Chart
- Revenue Trend Line Chart
- Revenue by Product Pie Chart
- Sales Details Table
- Date Range Control
- Region Filter
- Product Filter
- Interactive filtering
- Custom dashboard theme
- Public dashboard sharing

## Data Source

The dashboard uses a sales dataset stored in **Google Sheets**.

The dataset contains:

- Order ID
- Customer
- Region
- Product
- Quantity
- Revenue
- Cost
- Order Date

## Charts Created

### 1. Total Revenue Scorecard

Displays the total revenue generated from all sales records.

### 2. Revenue by Region

A bar chart showing revenue across different regions.

### 3. Revenue Trend

A line chart showing how revenue changes over time.

### 4. Revenue by Product

A pie chart showing the contribution of each product to total revenue.

### 5. Sales Details

A table containing detailed sales information such as:

- Order ID
- Customer
- Region
- Product
- Quantity
- Revenue

## Interactive Controls

### Date Range Control

Allows users to select a specific date range and analyse sales for that period.

### Region Filter

Allows users to filter the dashboard based on region.

### Product Filter

Allows users to filter the dashboard based on product.

## Data Analysis

The dashboard helps analyse:

- Total revenue
- Regional sales performance
- Product revenue contribution
- Sales trends over time
- Individual sales transactions
