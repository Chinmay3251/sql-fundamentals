## Objective

Explore an Indian retail business dataset, check data quality, calculate useful business metrics, create visualisations, generate an automated EDA report, and produce a business insights report with optional local AI assistance.

## Dataset

- File: `data/indian_retail_100k.csv`
- Target size: 100,000 rows
- Fields include order date, state, city, customer type, product, category, quantity, unit price, payment method, customer rating, and total sales.

**Data limitation:** The included 100k-row practice CSV is expanded by repeating rows from the supplied 1,500-row source dataset and assigning new order IDs. It is useful for practicing the workflow, but the repeated rows are not independent real-world transactions. Do not present findings as representative market research.

## Run the analysis

Run commands from the project folder:

```powershell
python eda_analysis.py
python sweetviz_analysis.py
python ai_insights.py
```

The EDA script creates data-quality and summary reports plus charts. Sweetviz creates an interactive HTML report. The AI insights script calculates metrics directly from the CSV and tries to use a local Ollama model if the server is available. If Ollama is unavailable, it writes a rule-based fallback report.

To configure a different local Ollama model, set the `OLLAMA_MODEL` environment variable, for example:

```powershell
$env:OLLAMA_MODEL = "qwen2.5:7b"
python ai_insights.py
```

## Main analyses

1. Dataset shape, column types, missing values, and duplicate rows.
2. Numeric summary statistics.
3. Total sales, average transaction sales, quantity sold, and unique products/states.
4. Sales by category, top states, and product performance.
5. Charts for category sales, state sales, monthly sales, and sales distribution.
6. Optional AI-assisted narrative and practical recommendations.
