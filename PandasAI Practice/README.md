# PandasAI Practice

This project explores using PandasAI for natural language data analysis with a real Indian dataset.

## Practical Tasks

- Installed PandasAI
- Loaded an Indian CSV dataset
- Ran 10 natural-language queries
- Compared PandasAI with manual Pandas
- Compared results for three questions
- Documented accuracy differences
- Added error handling
- Added error logging

## Tools Used

- Python
- Pandas
- PandasAI
- VS Code
- Git
- GitHub

## Error Handling

Failed PandasAI queries are handled using Python exception handling.

Errors are recorded in:

`error_log.txt`

## Comparison

PandasAI was compared with manual Pandas for three questions to check whether natural-language-generated analysis produced the same results as manually written Pandas code.
