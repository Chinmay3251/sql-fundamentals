# Customer Churn Analytics – End-to-End Project

This project is an end-to-end customer churn analytics project using a public Kaggle dataset.

## Business Question

What factors are associated with customer churn, and which customer groups should the business focus on to reduce churn?

## Project Workflow

The project follows the complete analytics workflow:

1. Data collection
2. Data cleaning
3. Exploratory Data Analysis
4. Data visualisation
5. Statistical analysis
6. Dashboard development
7. Business recommendations

## Data Cleaning

The dataset was checked for:

- Missing values
- Duplicate records
- Incorrect data types
- Invalid numeric values
- Data consistency

The `TotalCharges` column was converted to numeric format and missing values were handled.

## Exploratory Data Analysis

The analysis examined:

- Customer churn
- Contract type
- Payment method
- Customer tenure
- Monthly charges
- Internet service
- Customer characteristics

## Statistical Analysis

The project includes:

- Mean
- Median
- Standard deviation
- Pearson correlation
- Correlation matrix
- Distribution analysis

## Visualisations

The following charts were created:

- Churn Distribution
- Churn by Contract
- Churn by Payment Method
- Churn by Tenure
- Churn by Monthly Charges
- Correlation Heatmap

## Power BI Dashboard

The dashboard contains:

- Total Customers
- Churned Customers
- Churn Rate
- Average Monthly Charges
- Average Tenure
- Churn by Contract
- Churn by Payment Method
- Churn by Tenure
- Churn by Internet Service
- Interactive slicers

## Business Recommendations

Three recommendations were developed based on the analysis:

1. Focus on early-stage customer retention.
2. Review contract and pricing options.
3. Improve the payment experience.
